# MovieMatch

Movie recommendation Rails application

## Проєкт

Це веб-додаток на Ruby on Rails для рекомендацій фільмів.

## Технології

- Ruby on Rails
- PostgreSQL
- TMDB API
- Sentry (моніторинг)
- Winston-style logging

## Версія

**v1.0** — Перший стабільний реліз з логуванням та моніторингом.

```bash
bundle install
